# 🦷 Landing Page - Odontología Estética Moderna

Una página de aterrizaje (Landing Page) moderna, responsiva y accesible diseñada para un dentista independiente con enfoque en estética y tecnología dental. Este proyecto fue construido utilizando prácticas estándar de la industria, asegurando semántica HTML5 pura y un sistema de estilos flexible con CSS Moderno.

## 🚀 Características

- **Estructura Semántica Estricta:** Implementación limpia utilizando etiquetas como `<nav>`, `<header>`, `<main>`, `<section>`, `<article>` y `<footer>`.
- **Diseño Responsivo (Mobile-First):** Layouts fluidos adaptables a dispositivos móviles, tablets y pantallas de escritorio mediante el uso combinado de **CSS Grid** y **Flexbox**.
- **Accesibilidad (WCAG AA):** Alta legibilidad tipográfica, contrastes validados para evitar fatiga visual y estados de enfoque (`:focus`) visibles en elementos interactivos.
- **Arquitectura CSS Limpia:** Uso de **CSS Custom Properties (Variables)** para centralizar la paleta de colores, tipografía y espaciados, facilitando el mantenimiento futuro.

## 📁 Estructura del Contenido

La landing page se divide en las siguientes secciones clave:
1. **Navegación Principal:** Enlaces de ancla fluidos y llamada a la acción (CTA) para agendar.
2. **Hero Section:** Presentación del profesional con un enfoque moderno, joven y empático.
3. **Servicios Especializados:** Grid interactivo en formato de tarjetas individuales (`<article>`) que detallan los procedimientos estéticos.
4. **Trayectoria Académica:** Sección elegante que destaca el perfil formativo (Pregrado, Diplomados y Magíster).
5. **Testimonios Reales:** Carrusel o bloque de reseñas humanas y calificaciones de pacientes satisfechos.
6. **Formulario de Conversión:** Sistema directo de captura de leads (Nombre, Email y Procedimiento de interés).

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura y semántica.
- **CSS3** - Variables globales, Grid, Flexbox y Media Queries (Sin frameworks externos).
